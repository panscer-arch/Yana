Нужен вход

Отправить в GitHub

Команда git push origin games-publish готова, но текущий терминал не получил логин GitHub.

После push

Включить Pages

В настройках репозитория выбрать ветку games-publish и папку root для публикации.

Домен

Когда будет выбран красивый адрес, его можно подключить отдельным шагом.

1. Выбрать адрес

Например, короткое имя для сайта Яны. Пока адрес не выбран, файл CNAME не создаём.

2. Добавить CNAME

После выбора домена на сайт добавляется файл CNAME с этим адресом.

3. Проверить Pages

После настройки DNS GitHub Pages должен открыть сайт уже по домену.

Страница запуска помогает не потерять последние шаги перед публикацией.
