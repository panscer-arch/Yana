Правила, которые надо помнить

Обязательные работы

Их надо выполнить обязательно. В журнале они выделяются значком, а в расписании — оранжевой рамкой.

Если урок каждую неделю

Для 2–11 классов минимум оценок: I четверть — 5, II — 5, III — 7, IV — 5 по каждому предмету.

Если урок не каждую неделю

Для аттестации нужно выполнить все обязательные работы. Для технологии в 5–9 классах достаточно одной оценки за четверть.
