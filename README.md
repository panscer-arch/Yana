# Яна Единорог

Детский яркий сайт для игр, веб-разработок и обучения Яны.

## Что уже есть

- Главная страница с единорогом и быстрыми переходами.
- Сгенерированные дизайнерские ассеты: логотип и hero-иллюстрация единорога.
- Витрина игр с рабочей мини-игрой `Кошачья погоня` и игровой лабораторией для будущих проектов.
- Раздел обучения по математике.
- Генератор примеров: сложение, вычитание, умножение, деление.
- Режим `Микс`, где действия меняются случайно.
- Режим примеров в строку и в столбик.
- Подсказки, счет правильных ответов, ошибок, серии и награды.
- Дневная цель на 10 правильных примеров с сохранением в браузере.
- Таблица умножения от 1 до 10.
- Раздел `Студия Яны` с планом развития сайта.
- Раздел `Публикация` с путем до GitHub Pages и домена.
- Раздел `Дневник Яны` для идей и планов, с сохранением в браузере.
- Раздел `Школьная комната` с русским языком, чтением и задачами.
- Раздел `План недели` с расписанием Яны по дням.
- Раздел `Веб-проекты` для открыток, школьных страниц, галерей и мини-сайтов.
- Раздел `Галерея` для скриншотов игр, рисунков и лучших работ.
- Подготовка к публикации: favicon, manifest, sitemap, robots.txt и красивая 404-страница.
- Страница `Запуск сайта` с понятным чеклистом GitHub Pages и домена.

## Структура

- `index.html` - главная страница сайта.
- `assets/yana-unicorn-logo.png` - логотип сайта.
- `assets/yana-unicorn-hero.png` - главная иллюстрация.
- `games/index.html` - игровая лаборатория с готовыми играми и идеями.
- `games/cat-chase` - рабочая мини-игра `Кошачья погоня`.
- `school/index.html` - школьная комната с упражнениями.
- `schedule/index.html` - недельный план Яны.
- `projects/index.html` - мастерская веб-проектов Яны.
- `gallery/index.html` - галерея работ и скриншотов.
- `launch/index.html` - чеклист запуска сайта.
- `.nojekyll` - маркер для корректной публикации статического сайта на GitHub Pages.
- `site.webmanifest`, `robots.txt`, `sitemap.xml`, `404.html` - файлы для публикации сайта.

## Для Яны

Сайт задуман как личная мастерская: сюда можно добавлять новые игры, школьные тренажеры, маленькие сайты, заметки и галерею проектов.

## Проверка перед публикацией

```bash
npm run check
```

Команда проверяет HTML-страницы, внутренние ссылки, якоря, manifest, sitemap и обязательные файлы для GitHub Pages.

Если `npm` недоступен, можно запустить напрямую:

```bash
node scripts/check-site.mjs
```

Локальный сервер:

```bash
npm run serve
```

## Следующие шаги

- Доработать `Кошачью погоню` до полной версии с уровнями и скинами.
- Включить GitHub Pages.
- Подключить домен.
- Добавить новые учебные тренажеры и галерею проектов.
