# Яна Единорог

Детский яркий сайт для игр, веб-разработок и обучения Яны.

## Что уже есть

- Главная страница с единорогом и быстрыми переходами.
- Раздел `Быстрый старт` с понятным маршрутом на день для Яны.
- Сгенерированные дизайнерские ассеты: логотип и hero-иллюстрация единорога.
- Витрина игр с рабочими мини-играми `Кошачья погоня`, `Искорка: Паркур` и игровой лабораторией для будущих проектов.
- Раздел обучения по математике.
- Генератор примеров: сложение, вычитание, умножение, деление.
- Режим `Микс`, где действия меняются случайно.
- Режим примеров в строку и в столбик.
- Подсказки, счет правильных ответов, ошибок, серии и награды.
- Дневная цель на 10 правильных примеров с сохранением в браузере.
- Таблица умножения от 1 до 10.
- Раздел `Студия Яны` с планом развития сайта.
- Раздел `Публикация` с путем до GitHub Pages и домена.
- Раздел `Дневник Яны` для идей и планов, с сохранением в браузере.
- Раздел `Школьная комната` с русским языком, чтением и задачами.
- Раздел `План недели` с расписанием Яны по дням.
- Раздел `Веб-проекты` для открыток, школьных страниц, галерей и мини-сайтов.
- Раздел `Галерея` для скриншотов игр, рисунков и лучших работ.
- Раздел `Карта сайта` со всеми страницами портала в одном месте.
- Раздел `Установка` с инструкцией, как открыть сайт как приложение.
- Раздел `Приватность` с описанием локальных данных и кнопкой очистки.
- Раздел `Родителям` с кратким гидом по сайту, безопасности и публикации.
- Раздел `Обновления` с журналом развития сайта и ближайшими шагами.
- Подготовка к публикации: favicon, manifest, sitemap, robots.txt и красивая 404-страница.
- Лёгкий офлайн-слой: `sw.js` кэширует основные страницы и ассеты после открытия сайта на localhost или GitHub Pages.
- Страница `Запуск сайта` с понятным чеклистом GitHub Pages и домена.

## Структура

- `index.html` - главная страница сайта.
- `start/index.html` - быстрый старт и ежедневный маршрут по сайту.
- `assets/yana-unicorn-logo.png` - логотип сайта.
- `assets/yana-unicorn-hero.png` - главная иллюстрация.
- `games/index.html` - игровая лаборатория с готовыми играми и идеями.
- `games/cat-chase` - рабочая мини-игра `Кошачья погоня`.
- `games/parkour` - рабочая мини-игра `Искорка: Паркур`.
- `games/kolobok` - рабочая мини-игра `Колобок: Темная Тропа`.
- `games/snake-clash` - рабочая мини-игра `Snake Clash`.
- `school/index.html` - школьная комната с упражнениями.
- `schedule/index.html` - недельный план Яны.
- `projects/index.html` - мастерская веб-проектов Яны.
- `gallery/index.html` - галерея работ и скриншотов.
- `map/index.html` - карта сайта со всеми разделами.
- `install/index.html` - инструкция по установке сайта как приложения.
- `launch/index.html` - чеклист запуска сайта.
- `privacy/index.html` - приватность, безопасность и очистка локальных данных.
- `parents/index.html` - гид для родителей по сайту и следующим шагам.
- `updates/index.html` - журнал обновлений и следующих шагов.
- `.nojekyll` - маркер для корректной публикации статического сайта на GitHub Pages.
- `site.webmanifest`, `robots.txt`, `sitemap.xml`, `404.html` - файлы для публикации сайта.
- `sw.js` и `assets/site.js` - service worker и общий скрипт регистрации для офлайн-кэша.

## Для Яны

Сайт задуман как личная мастерская: сюда можно добавлять новые игры, школьные тренажеры, маленькие сайты, заметки и галерею проектов.

## Проверка перед публикацией

```bash
npm run check
```

Команда проверяет HTML-страницы, навигацию, подвал с быстрыми ссылками, внутренние ссылки, якоря, manifest, service worker, sitemap, обязательные файлы для GitHub Pages, достижимость страниц с главной и то, что все публикуемые страницы добавлены в sitemap и офлайн-кэш.

Если `npm` недоступен, можно запустить напрямую:

```bash
node scripts/check-site.mjs
```

Та же проверка настроена в GitHub Actions: `.github/workflows/site-check.yml`.

## Деплой

Сайт развернут на VPS в `/var/www/yana` и открывается на `https://barbarpatapim.com`.

Автодеплой настроен через GitHub Actions workflow `.github/workflows/deploy-yana.yml`: при push в ветку `games-publish` выполняется проверка сайта и синхронизация файлов на сервер. Для работы workflow в GitHub Secrets нужен секрет `YANA_DEPLOY_KEY` с приватным SSH-ключом deploy-пользователя.

Локальный сервер:

```bash
npm run serve
```
