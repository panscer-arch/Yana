Перед доменом

Публикация

  1. Отправить ветку games-publish в GitHub.
  2. Включить GitHub Pages для репозитория.
  3. Проверить публичную ссылку.
  4. Подключить домен, когда будет выбран адрес.

Как доводить дальше

Практичные направления, которые помогут сайту расти без хаоса.

Добавлять игры

Каждую новую игру лучше класть в отдельную папку внутри games, а потом добавлять карточку в витрину.

Расширять обучение

Следующие тренажёры можно добавлять по школьным темам: русский язык, чтение, задачи, диктанты и таблица умножения.

Сохранять понятность

После каждого крупного шага полезно обновлять журнал изменений и запускать проверку сайта перед публикацией.
