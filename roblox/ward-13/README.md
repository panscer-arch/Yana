# Палата №13 для Roblox Studio

Это не сайт. Это builder-скрипт для настоящего Roblox Studio.

## Как открыть

1. Открой Roblox Studio.
2. Создай пустой проект `Baseplate`.
3. Нажми `View -> Command Bar`.
4. Открой файл:
   `/Users/anaspiridonova/Documents/Codex/work/Yana/roblox/ward-13/Palata13_Builder.lua`
5. Скопируй весь текст файла.
6. Вставь в `Command Bar` в Roblox Studio.
7. Нажми `Enter`.
8. Нажми `Play`.

## Что создаётся

- палата и коридор;
- кровать, тумба, шкаф, стол;
- дверь выхода;
- ключ, батарейка и предохранитель;
- пациент-монстр;
- красный свет и белый свет;
- правило: при красном свете нельзя двигаться;
- правило: при белом свете пациент замирает, если на него смотреть;
- концовка с фразой монстра.

## Управление

- `WASD` или стрелки — ходить;
- мышка — смотреть;
- `E` или кнопка ProximityPrompt — взять предмет / открыть дверь.
