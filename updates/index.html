Что дальше

Оставшиеся шаги, которые действительно приближают сайт к “идеалу”.

Нужна авторизация

Залить изменения в GitHub

Локальные коммиты готовы, но push требует вход в GitHub из терминала. После авторизации можно отправить ветку games-publish.

После push

Включить Pages и домен

Когда ветка окажется на GitHub, останется включить GitHub Pages, проверить публичную ссылку и добавить домен, когда будет выбран адрес.
